How admin sign-in works

The console is for people with the Admin role. Admins can open every door at any time and do everything here: enroll people, edit the access schedule, read the audit log, record clips and run the evaluation. Students, staff, contractors and visitors only use the kiosk.

Identify yourself with a live face check (liveness plus a random blink or head-turn cue, recognised only among admins) or with your email, then enter the code from your authenticator app. Schedule edits and adding or removing an admin always ask for a fresh face check (or a one-time recovery code if the webcam fails).

Every sign-in attempt and face check is recorded in the audit log.
