How staff sign-in works

Three factors: your user ID, a live face check (liveness with a random blink or head-turn cue, matched only against you), and a code from your authenticator app. Policy edits and role changes ask for a fresh face check. Recovery codes replace the face check once each, if a webcam fails.

Policy adminEverything, including editing the access schedule and granting roles
OperatorEnroll people, record test clips, run the evaluation, kiosk demo controls
AuditorRead-only: audit log, access schedule, results

Every sign-in attempt and face check is recorded in the audit log.
